# UTN - Hackathon

Este proyecto está diseñado para gestionar los inscriptos en una Hackathon de la UTN. Está desarrollado utilizando React.js en el frontend.

## Pasos para ejecutar el proyecto

Sigue los pasos a continuación para correr el proyecto en tu máquina local:

### 1. Clona el repositorio

Clona el repositorio usando el siguiente comando:

```bash
git clone https://github.com/oscaralfrm/proyecto-beca-mb-grupo1-2025.git
```

### 2. Cambia a la rama "Frontend"

Crea y cambia a la rama `Frontend`:

```bash
git checkout -b "Frontend"
```

### 3. Obtén los últimos cambios de la rama "Frontend"

Asegúrate de tener los últimos cambios de la rama:

```bash
git pull origin Frontend
```

### 4. Ingresa a la carpeta del proyecto

Dirígete a la carpeta del frontend:

```bash
cd Frontend
```

### 5. Instala las dependencias

Instala todas las dependencias necesarias para el proyecto:

```bash
npm install
```

### 6. Construye el proyecto

Genera los archivos de construcción (build) del proyecto:

```bash
npm run build
```

### 7. Ejecuta el proyecto en modo de desarrollo

Levanta el servidor de desarrollo para ejecutar la aplicación:

```bash
npm run dev
```

Una vez que hayas ejecutado estos pasos, podrás acceder a la aplicación en tu navegador local en la URL especificada por el entorno de desarrollo.

## Notas

- Asegúrate de tener `Node.js` y `npm` instalados en tu máquina.
- Si encuentras algún problema o necesitas más detalles sobre la configuración, consulta la documentación oficial de React.js.
